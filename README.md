# Skyglass Weather 🌦️

Skyglass is a modern, minimalist weather application that provides real-time weather information with beautiful background animations and ambient sound effects.

## Features

- **Live Weather Updates**: Fetch real-time weather data for any city using the Open-Meteo API.
- **Dynamic Themes**: The interface background and ambient orbs change based on the current weather condition (Sunny, Rainy, Snowy, Foggy, etc.).
- **Background Animations**: Smooth, high-performance canvas animations for rain, snow, and thunder.
- **Ambient Sound**: Immersive sound effects for rain and thunder to enhance the weather experience.
- **Location Detection**: Use your browser's geolocation to get instant weather updates for your current position.
- **Glassmorphism UI**: A sleek, modern design with frosted glass effects and vibrant color accents.

## Tech Stack

- **HTML5**: Semi-semantic structure.
- **CSS3**: Custom properties (variables), glassmorphism, and keyframe animations.
- **JavaScript**: Fetch API for geocoding and weather data, Canvas API for animations.
- **API**: [Open-Meteo](https://open-meteo.com/) for free weather and geocoding data.

## How to Use

1. **Search by City**: Enter the name of a city in the search bar and press "Search" or hit Enter.
2. **Use My Location**: Click the "Use My Location" button to automatically fetch weather for your current area.
3. **Experience the Weather**: Watch the background and ambient orbs adapt to the weather, and listen for sound effects during rain or storms.

## Project Structure

- `index.html`: The main entry point.
- `style.css`: All styling and theme definitions.
- `script.js`: Core logic for API integration and animations.
